# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Igra KAS Bridge, **please do not open a public issue.**

Instead, report it privately:

- **Email:** [security@kat.foundation](mailto:security@kat.foundation)
- **Subject:** `[igra-kas-bridge] Security Vulnerability`

Include as much detail as possible:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within **48 hours** and aim to provide a fix or mitigation plan within **7 days** for critical issues.

## Scope

This policy covers the `igra-kas-bridge` client application. It does **not** cover:

- The Kaspa network or Kaspa WASM SDK (report to [kaspanet/rusty-kaspa](https://github.com/kaspanet/rusty-kaspa))
- The Igra L2 network (report to [Igra Labs](https://igralabs.com))
- Browser wallet extensions (Kastle, KasWare)

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest on `main` | Yes |
| Older releases | Best effort |

## Disclosure

We follow coordinated disclosure. We will credit reporters in the release notes unless anonymity is requested.
